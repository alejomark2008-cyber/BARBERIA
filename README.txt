BARBERÍA - PROTOTIPO PARA PORTAFOLIO DE DIGIAR RV

1. Sube index.html, style.css, script.js y la carpeta assets a GitHub.
2. Conecta el repositorio con Vercel.
3. Todos los datos de contacto, sedes, horarios y nombres son ficticios.
4. Los cuadros de barberos funcionan como perfiles sin fotografía.
5. Al tocar un servicio o barbero aparece una ventana con información.
